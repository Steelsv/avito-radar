# SETUP - подключение и запуск Avito Radar

Гайд для человека, который раньше этого не делал. Порядок шагов: создать бота, узнать свой chat_id, привязать Mini App, запустить локально, потом выложить в облако для работы 24/7.

## 1. Создание бота в Telegram

1. Откройте Telegram, найдите @BotFather.
2. Отправьте команду /newbot.
3. Введите имя бота (например, «Avito Radar»), затем username (должен заканчиваться на «bot», например «avito_radar_my_bot»).
4. BotFather пришлёт токен вида `1234567890:AAE...`. Скопируйте его - это TELEGRAM_BOT_TOKEN.

Включение платежей Telegram Stars (для продажи PRO внутри бота):
1. В @BotFather отправьте /mybots, выберите своего бота.
2. Payments -> Telegram Stars -> включите.
3. Провайдер платежей для Stars не нужен, всё работает внутри Telegram.

## 2. Свой chat_id

1. Напишите боту @userinfobot любое сообщение.
2. Он ответит вашим числовым id (например, `123456789`). Это TELEGRAM_CHAT_ID - идентификатор владельца: вам PRO выдается навсегда автоматически.

## 3. Mini App (веб-терминал внутри Telegram)

Mini App - это сайт, который открывается прямо в Telegram по кнопке «Терминал радара».

1. Сначала нужен публичный адрес сайта с HTTPS (например, после деплоя на Render - `https://avito-radar.onrender.com/`). Локальный `http://localhost` Telegram не примет: HTTPS обязателен.
2. В @BotFather отправьте /newapp (или /setmenubutton для существующего бота).
3. Выберите бота, укажите короткое имя и URL сайта.
4. Итоговый адрес вида `https://ваш-домен/` запишите в переменную MINI_APP_URL.

## 4. Локальный запуск

Нужен Python 3.10+.

1. Склонируйте репозиторий и откройте папку в терминале.
2. Создайте виртуальное окружение: `python -m venv venv`.
3. Активируйте его: Windows - `venv\Scripts\activate`, Linux/Mac - `source venv/bin/activate`.
4. Установите зависимости: `pip install -r requirements.txt`.
5. Скопируйте `.env.example` в `.env` и заполните минимум три переменные:
   - `TELEGRAM_BOT_TOKEN` - токен из шага 1;
   - `TELEGRAM_CHAT_ID` - ваш id из шага 2;
   - `MINI_APP_URL` - адрес Mini App из шага 3 (пока нет деплоя - оставьте значение по умолчанию).
6. Запуск: `python run.py bot`. На Windows можно просто двойным кликом `start_bot.bat`.
7. Напишите боту /start - должно прийти главное меню.

## 5. Деплой на Render (круглосуточная работа)

Локальный компьютер выключается, поэтому автоматизация 24/7 живет в облаке. В репозитории уже есть `render.yaml`.

1. Зарегистрируйтесь на render.com и залейте репозиторий на GitHub.
2. В панели Render: New -> Blueprint, выберите репозиторий. Render прочитает `render.yaml` и создаст сервис.
3. В панели Render -> Environment добавьте переменные:
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` - из шагов выше;
   - `MINI_APP_URL` - `https://ваш-домен.onrender.com/`;
   - `PORT` - порт HTTP-сервера (например, 7860);
   - `DATA_REPO_URL` - URL приватного git-репозитория для сохранения данных (радары, пользователи) между рестартами. Без него free-тариф стирает диск.
4. Как создать DATA_REPO_URL:
   - создайте на GitHub приватный репозиторий (например, `avito-radar-data`);
   - сгенерируйте personal access token: Settings -> Developer settings -> Tokens (classic) -> Generate new token, отметьте scope «repo»;
   - подставьте в URL: `https://<ваш-логин>:<токен>@github.com/<ваш-логин>/avito-radar-data.git`.
5. Free-тариф Render засыпает через ~15 минут без запросов и бот перестает сканировать. Лечение: зарегистрируйтесь на uptimerobot.com, добавьте монитор типа HTTP, URL `https://ваш-домен.onrender.com/health`, интервал 5 минут. Пинг держит сервис awake.

## 6. ЮKassa и СБП (опционально)

Если хотите принимать оплату картой или СБП помимо Telegram Stars:

1. Зарегистрируйтесь на yookassa.ru, создайте магазин.
2. Из личного кабинета возьмите shopId и секретный ключ.
3. Пропишите их в переменные окружения: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET`.
4. В личном кабинете ЮKassa настройте вебхук (HTTP-уведомления) на адрес `https://<ваш-домен>/webhook/yookassa`, событие `payment.succeeded`. Без вебхука оплата проходит, но PRO не активируется автоматически.

## 7. Команды владельца

Работают только для chat_id из TELEGRAM_CHAT_ID, остальные их не видят.

- `/grant <user_id> [days]` - выдать PRO на N дней. Пример: `/grant 123456789 30`. Без числа - 30 дней по умолчанию.
- `/grant <user_id> forever` - выдать PRO навсегда. Пример: `/grant 123456789 forever`.
- `/revoke <user_id>` - снять PRO. Пример: `/revoke 123456789`.
- `/users` - статистика: сколько всего пользователей, из них PRO и free, список до 20 строк.

В главном меню у владельца есть кнопка «Админка» с этим списком.

## 8. Как это работает

Бот каждые ~2 минуты (инвал настраивается) сканирует все активные радары на Авито. Новые объявления проходят анти-мусорные фильтры (байт-цены, аксессуары, перекупы) и уходят пушем с фото, ценой, выгодой и кнопками. PRO-пользователи получают пуши сразу, Free - с задержкой 15 минут. Владелец (TELEGRAM_CHAT_ID) - вечный PRO без ограничений.

## 9. Траблшутинг

- Бот молчит: проверьте TELEGRAM_BOT_TOKEN в .env (попросите у бота /status). Если процесс завис, удалите файл `data/bot.lock` и перезапустите.
- Mini App белый экран: проверьте, что MINI_APP_URL начинается с `https://` и сайт доступен по этому адресу.
- Авито капча: решатель PoW уже встроен, отдельно ничего ставить не нужно. При массовых блокировках увеличьте интервал проверки в настройках мониторинга (2 мин -> 5 мин).
- Оплата не активирует PRO: для Stars - проверьте, что платежи включены в @BotFather; для ЮKassa - что вебхук payment.succeeded доходит (логи в панели Render).
