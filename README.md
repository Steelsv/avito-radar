# 🛰️ Avito Radar — Личный интеллектуальный монитор и парсер Авито

Автономный инструмент для быстрого парсинга, анализа рынка и отслеживания новых объявлений на Авито в реальном времени.

Полностью **отвязан от любых внешних сервисов, сторонних авторов и платных капча-сервисов**. Чистый, красивый и автоматизированный скрипт под личные задачи.

---

## ✨ Ключевые возможности

- 🎯 **Универсальность для любых категорий**: электроника (iPhone, видеокарты, ноутбуки), недвижимость (квартиры, дома), авто, запчасти, мебель и любые другие товары.
- 🔗 **Добавление в 1 клик по ссылке**: скопируйте ссылку из адресной строки браузера с любыми фильтрами — скрипт сам определит город, категорию, декодирует фильтры и применит их к API.
- 🛡️ **Обход защиты Авито**:
  - Встроенный чистый Python-солвер для SHA-256 Proof-of-Work (`firewallPow`, HTTP 439).
  - Обработка проверок Qrator (генерация XTEA-отпечатков).
  - Имитация сетевого TLS-стека реального браузера через `curl-cffi` (Firefox).
- 📊 **Анализ рынка и поиск выгодных сделок**:
  - Автоматический расчёт медианной рыночной цены с отсевом аномалий.
  - Подсветка выгодных предложений (например: `🔥 Выгодно (-25%)`).
- 🕵️ **Фильтрация посредников и перекупов**:
  - Для недвижимости: отделение прямых собственников от риелторов и агентств.
  - Для товаров: отсев перекупщиков и магазинов с десятками завершённых объявлений.
  - Проверка старых переопубликованных объявлений по счётчикам просмотров (общие vs сегодняшние).
- 🤖 **Интерактивное управление из Telegram кнопками**:
  - Создавайте поиски прямо из телефона: выбирайте товар и город по кнопкам или просто отправляйте ссылку на Авито в чат!
  - Получайте готовые Excel-таблицы файлом прямо в Telegram в 1 клик.
  - Включайте и выключайте мониторинг на лету.
- 📱 **Telegram-уведомления в реальном времени**:
  - Мгновенные пуши о новых лотах с фото, ценой, выгодой относительно рынка, адресом и прямой ссылкой.
- 📑 **Экспорт в стильный Excel (.xlsx)**:
  - Цветовая подсветка сделок (зелёный — выгодно, серый — агентства).
  - Активные гиперссылки «Открыть» для быстрого перехода к объявлению.
  - Автоподбор ширины колонок, автофильтры и закреплённые заголовки.

## 💻 Использование через командную строку (CLI)

Для автоматизации, планировщиков (cron / Windows Task Scheduler) или фонового запуска доступны прямые команды:

### 1. Добавить новый поиск
```bash
python run.py add "https://www.avito.ru/moskva/telefony/apple/iphone_15-ASgBAgICA0SywA2SoO0RtMANzqs5sMENiPw3"
```
*Можно задать своё короткое имя флагом `--name iphone15_msk`.*

### 2. Собрать все объявления (Scan)
```bash
python run.py scan iphone_15_moskva
```
*Скрипт постранично скачивает каталог, сохраняет историю в `data/` и формирует итоговый Excel в папке `output/`.*

### 3. Запустить мониторинг новых объявлений (Watch)
```bash
python run.py watch iphone_15_moskva --interval 120
```
*При старте скрипт запоминает текущую выдачу, а затем присылает уведомления в консоль и в Telegram о каждом свежем объявлении.*

### 4. Экспорт в Excel
```bash
python run.py export iphone_15_moskva
```

### 5. Настройка Telegram
```bash
python run.py telegram --setup   # Интерактивная привязка бота
python run.py telegram --test    # Отправка тестового пуша
```

## 📁 Структура проекта

```text
avito/
├── avito_radar/                 # Основной пакет логики
│   ├── core/                    # Сетевой клиент, PoW и Qrator байпас
│   │   ├── client.py            # curl_cffi сессия с TLS-fingerprint
│   │   ├── pow_solver.py        # Решение SHA-256 задач без сторонних API
│   │   └── qrator.py            # XTEA кодек и воспроизведение cookie-цепочки
│   ├── parsers/                 # Разбор ссылок и объявлений
│   │   ├── url_resolver.py      # Декодирование varint-фильтров из URL
│   │   └── item_parser.py       # Парсинг данных лота и страницы просмотров
│   ├── analysis/                # Интеллектуальный анализ
│   │   ├── market.py            # Расчёт рыночной цены и детекция скидок
│   │   └── classifier.py        # Классификация продавцов (собственник/перекуп)
│   ├── notifications/           # Оповещения
│   │   └── telegram.py          # Telegram Bot API клиент
│   ├── exporters/               # Выгрузка данных
│   │   └── excel.py             # Формирование стилизованного Excel
│   ├── storage/                 # Хранилище
│   │   └── db.py                # Управление JSON-базой и историей
│   ├── config.py                # Конфигурация и задержки
│   └── engine.py                # Сценарии Add / Scan / Watch
├── data/                        # Сохранённые поиски и кэш (не уходит в git)
├── output/                      # Готовые таблицы Excel (.xlsx)
├── tests/                       # Модульные тесты
├── requirements.txt             # Зависимости
├── run.bat                      # Лаунчер для Windows в 1 клик
├── run.py                       # Главная точка входа (TUI и CLI)
└── README.md                    # Документация
```

## ⚙️ Установка зависимостей (при переносе на другой ПК)

```bash
pip install -r requirements.txt
```
Зависимости минимальны: `curl-cffi`, `openpyxl`, `rich`, `questionary`.

## 🔒 Безопасность и личные данные

- Все ваши токены Telegram хранятся только локально в `data/telegram.json`.
- Вся база объявлений и история виденных лотов хранится локально на вашем компьютере в `data/searches/`.
- Никакие данные никуда не отправляются.
